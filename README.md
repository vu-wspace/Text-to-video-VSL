### Khởi tạo môi trường ảo (Linux/WSL)

```
python3 -m venv .venv
source .venv/bin/activate
```

### Cài đặt các thư viện liên quan

```
pip3 install underthesea
pip3 install -U 'moviepy>=2.0'
pip3 install mediapipe==0.10.13
pip3 install protobuf==4.25.9
```

### Thoát khỏi môi trường ảo

```
deactivate
```
